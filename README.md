# Clase 15 — Desarrollo de dApps e integración Web3

Ejemplos de clase (JavaScript, Vite, Ethers.js v6 y MetaMask).

## Proyectos

- `01/`: conexión con MetaMask y firma de mensajes.
- `02/`: ABI y lecturas de un ERC-20.
- `03/`: transferencias, aprobaciones y allowance.
- `04/`: eventos de MetaMask y sincronización de la interfaz.

## Ejecutar

Cada carpeta es un proyecto independiente. Desde la carpeta elegida:

```bash
npm ci
npm run dev
```

Necesitás Node.js, navegador con MetaMask y, para las demos que interactúan con el token, un contrato ERC-20 de práctica desplegado en Sepolia. Usá exclusivamente cuentas de prueba.

No se incluyen `node_modules`, archivos generados ni datos de tu equipo.
